# CV Website Template

A personal CV website that reads all its content from one Excel file. No coding.

- `index.html`: the website engine. No need to edit it.
- `cv-data.xlsx`: your content. The first sheet, **How to deploy**, has the full steps.
- `photo.jpg`: replace with your own photo.
- `vendor/`: SheetJS 0.18.5 (Apache-2.0) reads the Excel file. jsPDF 2.5.1 (MIT) builds the PDF CV.

Quick start: download [cv-website-template.zip](cv-website-template.zip), fill in `cv-data.xlsx`, upload the folder to a GitHub repository, and turn on GitHub Pages.

Live demo: https://ramizassaf.github.io/ramizassaf/template/
